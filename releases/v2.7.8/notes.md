# AKRX World Manager 2.7.8

- Écran des patchs simplifié : un clic sur un préréglage affiche ses patchs et l'enregistrement ferme l'outil.
- Le lancement vérifie les conflits uniquement entre patchs actifs. Un patch absent du préréglage choisi est désactivé.
- Nouvel outil « Fixer un patch » : réattribue les FileDataID depuis 927000000 par défaut, conserve les .wdt et sauvegarde l'ancien patch.json.
