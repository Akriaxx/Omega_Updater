# AKRX World Manager 2.7.0

- Terminal plus sombre, champ de saisie invisible avec curseur clignotant et focus automatique.
- Accueil animé sur trois lignes : Bienvenue.... / Créateur... / Que veux-tu créer aujourd’hui ?
- Fond animé ascendant mêlant code numérique et runes vectorielles.
- Bibliothèque Noggit unifiée : projets locaux en vert, projets suivis sur GitHub en violet.
- Ajouter un projet par son nom et son URL GitHub.
- Bouton Modifier : nom et dépôt indépendants pour chaque projet, y compris les projets locaux à publier.
- Installation et mise à jour des projets suivis ; leur origine reste conservée après téléchargement et redémarrage.
- Protection des dossiers locaux face aux collisions entre projets et dépôts.

Les réglages existants sont conservés. Le retour au launcher se fait toujours par trois clics sur le logo.
